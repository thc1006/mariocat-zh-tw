🧪 WebAssembly 端口（v2.0 routine 紀錄）

本專案 5,500 行 C++ 源碼經過 23 輪 build + lib 源碼 patch，與 Emscripten 3.1.20 + DxLib HTML5 整合到極深層級。已修通：跨平台 #ifdef 守衛、COOP/COEP service worker（解 SAB）、自編 DxLib HTML5 lib、Asyncify 物件 scope hoisting、Module.Asyncify 命名空間 patch、修補 lib EM_ASM_INT brace bug（DxLib v3.24b 內 #ifdef ASYNCIFY 區段未測過的真實 bug）。

無法跨越的最後關卡：emscripten 3.1.20 的 ASYNCIFY wasm-level instrumentation 不認得 DxLib lib 內 audio decode 的 indirect call chain，rewind 進入 wasm unreachable trap。需要精確的 emscripten 版本 bisect（可能不存在）、 或大改 DxLib 整個 audio subsystem 改用 emscripten 3.x 的 promise integration pattern。屬於上游 lib 維護工作。

→ 開啟實驗版（黑屏／技術參考） ｜ → 23 個 commit 軌跡 ｜ → lib 源碼 patch（含 brace bug 修正）

本繁中化做了什麼

📖 全程式碼翻譯

5,551 行原作日文註解、92 條遊戲台詞，全部翻成台灣繁體中文。

🌶 PTT/Dcard 在地化

不是直譯。「貴様の死に場所はここだ」變「你的葬身之地就在這」、「屑が」變「雜碎」、「俺、最強」變「老子最頂」。

💀 死亡計數嗆聲

累積死到第 5 / 30 / 70 / 150 / 500 次，視窗標題會冒出來酸你。500 次：「你已經沒救了 但繼續加油」。

🎲 5 條新死亡哏

「我選擇死亡」「笑死 又寄了」「已寄爆」「真的會謝」「不忍卒睹」混進原作的死亡台詞池裡。

📦 單檔 portable

朋友拿到單一 .exe 雙擊即玩，自動解壓 + 執行 + 清理。不用任何資料夾。

🔧 64-bit 重編

原作是 2007 年的 32-bit .exe。本版重新用 MinGW-w64 GCC 12.2 編成 64-bit、靜態連結，現代 Windows 直接跑。

怎麼開始玩

  1. 點上方「下載 Windows 版」取得 MarioCat_zh_Launcher.exe
  2. Windows Defender / SmartScreen 會擋一下沒簽署的 .exe，請點「其他資訊」→「仍要執行」
  3. 遊戲會自動跳出。鍵盤操作：
